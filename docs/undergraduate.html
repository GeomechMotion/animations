Animations for Undergraduates

The animations presented here were created using various constitutive models in PLAXIS. However, they aim to represent the classic behavior that should typically be observed when performing triaxial tests.

This page only contains the following triaxial tests:

  • Triaxial CIUC test - Isotropically Consolidated Undrained
  • Triaxial CIDC test - Isotropically Consolidated Drained
  • CPTWidget Cavity Expansion - Cavity expansion model made with Norsand to estimate the state parameter.

These tests are performed on normally consolidated and overconsolidated clay samples, as well as dense and loose sand samples.
